# 📊 Amazon Sales Analytics Dashboard

An interactive **Power BI dashboard** built to analyze Amazon sales data and provide actionable business insights. This project helps stakeholders monitor sales performance, profitability, customer behavior, and product trends through dynamic visualizations.

---

## 🚀 Project Overview

The Amazon Sales Analytics Dashboard transforms raw sales data into meaningful insights using Power BI. It enables users to explore sales metrics, identify top-performing products, track regional performance, and analyze customer purchasing patterns.

---

## 📌 Features

- 📈 Sales Performance Analysis
- 💰 Revenue & Profit Tracking
- 🛍️ Product Category Analysis
- 🌍 Region-wise Sales Overview
- 👥 Customer Segment Analysis
- 📅 Monthly & Yearly Sales Trends
- 🔍 Interactive Filters and Slicers
- 📊 KPI Cards for Quick Insights

---
